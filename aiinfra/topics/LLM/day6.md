### 学习任务 1：标准残差连接回顾 —— 从 ResNet 到 Transformer 的"标配"（30 分钟）

#### ResNet（2016）：解决深度网络的梯度消失

2015 年 ResNet 之前，网络越深训练越难——梯度在反向传播中逐层衰减（梯度消失），深层网络反而比浅层差。ResNet 的解法极其简单：

$$h' = h + F(h)$$

- $h$：输入（**恒等映射**，直接加过去）
- $F(h)$：残差函数（网络要学的"增量"）
- $h'$：输出 = 输入 + 增量

**为什么有效**：网络只需学"增量" $F(h)$，不用从零学完整映射 $h'$。如果某层不需要做变换，$F(h) \to 0$，$h' = h$——恒等映射天然是优化起点。梯度反向传播时，$h$ 的路径是直通的（无乘法），不会衰减。

#### Transformer（2017）：全盘继承残差连接

Transformer 的每个子层（attention + FFN）都用残差连接 + LayerNorm：

```
标准 Transformer 层:
  h₁ = LayerNorm(h + Attention(h))       ← 残差连接 + LN
  h₂ = LayerNorm(h₁ + FFN(h₁))           ← 残差连接 + LN
  输出 = h₂
```

从 2017 到 2026，几乎所有大模型（GPT、Llama、Qwen、DeepSeek V2/V3、Kimi K1.5/K2）都原封不动地继承这个设计——**残差连接是 9 年来从未被挑战的"标配"**。

#### 残差连接的隐含假设与局限

标准残差连接有一个隐含假设：**恒等映射对所有维度同等重要**——$h$ 的每个维度都无差别地"跳过"子层。但这个假设在超深网络和超大规模下开始松动：

| 局限 | 描述 | 后果 |
|------|------|------|
| **维度无差别** | 所有维度用相同的"跳过强度"（1.0） | 有些维度需要更多变换、有些需要更少——恒等映射不够灵活 |
| **深层累积** | 残差不断累加 $h_L = h_0 + \sum_{l} F_l(h_l)$ | 深层网络的残差累积过大，数值不稳定 |
| **缩放不适配** | 恒等映射的"权重"固定为 1 | 不同层、不同深度可能需要不同的残差强度 |

> 💡 **这就是 AttnRes 的切入点**：标准残差是"无脑全加"（identity + delta），AttnRes 提出用**注意力来调制残差**——让模型自己学"哪些维度该多保留、哪些该多变换"。这不是小优化，而是对 9 年来"标配"的范式级挑战。

### 学习任务 2：Attention Residuals 精读 —— 用注意力调制残差（60 分钟，今日核心）

精读《Attention Residuals》独立论文。AttnRes 是 K3 的两大架构创新之一——可"即插即用"替换标准残差连接，且带来一致的 scaling 收益。

#### 核心思想：从"恒等 + 增量"到"注意力调制"

标准残差：$h' = h + F(h)$——$h$ 以**恒等权重 1** 跳过子层。

AttnRes 的关键改变：用注意力机制让 $h$ 的每个维度获得**不同的跳过权重**：

$$h' = \text{AttnRes}(h, F(h))$$

展开来看，AttnRes 的概念结构：

$$h' = h \odot \alpha(h) + F(h) \odot \beta(h)$$

- $\alpha(h)$：**保留门**——控制输入 $h$ 每个维度保留多少（替代恒等 1）
- $\beta(h)$：**变换门**——控制子层输出 $F(h)$ 每个维度采纳多少
- $\odot$：逐元素乘（element-wise gate）
- $\alpha, \beta$：由注意力机制计算，**内容相关**——不同输入、不同维度有不同的门控值

#### 和标准残差的关系

| 特性 | 标准残差 $h + F(h)$ | AttnRes $h \odot \alpha + F(h) \odot \beta$ |
|------|---------------------|---------------------------------------------|
| 跳过权重 | **恒定 1**（所有维度相同） | **学习的**（每维度不同，内容相关） |
| 变换权重 | **恒定 1** | **学习的** |
| 灵活度 | 低（二选一：全留 or 全变） | 高（每维度独立调配留/变比例） |
| 退化 | — | $\alpha{=}1, \beta{=}1$ 时退化为标准残差 |
| 额外参数 | 0 | 门控注意力的小矩阵 |

> 💡 **AttnRes 是标准残差的超集**：当 $\alpha = 1, \beta = 1$ 时，AttnRes 退化为标准残差 $h + F(h)$。所以 AttnRes 的"额外能力"是让模型**可以选择**在某些维度/某些层上用非恒等的残差权重——标准残差是它的一个特例。

#### 为什么带来"一致的 scaling 收益"

"一致 scaling 收益"意味着：模型越大（层数越多、参数越多），AttnRes 相比标准残差的性能增益越稳定。三个原因：

| 原因 | 机制 |
|------|------|
| **深层适配** | 标准残差在深层累积过大；AttnRes 的门控可以自适应调低深层残差强度，缓解累积 |
| **维度专精** | 不同维度承载不同语义信息——有些需要强变换（语义重组），有些需要弱变换（保持记忆）；AttnRes 让每维度独立调配 |
| **优化更稳** | 门控提供了额外的梯度调节路径——梯度可以通过门控绕过不稳定区域，类似但比标准残差更灵活 |

#### "即插即用"的工程价值

AttnRes 的一个关键卖点：**不需要改模型架构，只需把 $h + F(h)$ 换成 $\text{AttnRes}(h, F(h))$**。

| 维度 | 说明 |
|------|------|
| 替换范围 | 所有残差连接点（attention 残差 + FFN 残差） |
| 额外参数 | 门控注意力的小投影矩阵（参数量 << 子层本身） |
| 兼容性 | 可与 MLA/MoE/DSA 等任意子层创新叠加 |
| 迁移成本 | 低——不改训练流程、不改并行策略、不改推理引擎 |

> ⚠️ **回答关键问题：AttnRes 和 2016 年 ResNet 残差连接的本质区别是什么**？ResNet 的残差是**恒等映射**——$h' = h + F(h)$，输入 $h$ 以固定权重 1 无差别地跳过子层，所有维度获得相同的"保留强度"。AttnRes 把恒等映射换成**注意力调制的门控**——$h' = h \odot \alpha(h) + F(h) \odot \beta(h)$，每个维度的保留/变换强度由注意力机制动态计算，内容相关。本质区别是"固定 vs 学习""无差别 vs 维度专属"——标准残差假设"所有维度都该同等跳过"，AttnRes 打破这个假设让模型自己学最优调配。这就是为什么 AttnRes 带来"一致 scaling 收益"：模型越大越深，维度间差异和深层累积问题越严重，AttnRes 的自适应门控越有价值。

> 💡 **连接 Day 1**：Day 1 学的 MLA 也是一种"打破默认假设"的创新——标准 attention 假设"每个头存完整的 K/V"，MLA 打破它用低秩压缩。AttnRes 同理——标准残差假设"恒等映射最好"，AttnRes 打破它用注意力门控。两者都是"找到默认设计中的隐含假设，然后挑战它"的创新方法论。

### 学习任务 3：KDA 精读 —— Kimi Delta Attention（50 分钟，今日核心）

精读 K3 技术报告的 KDA 章节。KDA（Kimi Delta Attention）是 K3 的另一大架构创新——一种新型注意力机制。

#### 架构定位：KDA 属于注意力层创新

把 Day 1-4 学的注意力方案按"改什么"分类：

| 创新层面 | 代表方案 | 改了什么 |
|---------|---------|---------|
| **KV 表示压缩** | MLA（Day 1） | 缓存什么（576 维潜向量 vs 32768 维） |
| **计算稀疏化** | DSA（Day 4） | 算哪些（Top-N 块 vs 全部） |
| **softmax 替换** | 线性注意力（Day 4） | 怎么算（核函数 vs softmax） |
| **???** | **KDA（今天）** | ? |

KDA 属于注意力层的创新，但它改的不是"缓存/稀疏/softmax"——而是注意力计算的**基本结构**。

#### Delta 的直觉：关注"变化"而非"原始值"

"Delta"在信号处理中指"变化量"——$\Delta x_t = x_t - x_{t-1}$。KDA 的核心思路：**注意力不应该直接作用在原始 token 表示上，而应该作用在"token 之间的变化"上**。

标准注意力的 $QK^T$ 直接用 token 的原始表示算相似度。KDA 的思路是先提取"delta"（token 间的变化模式），再在 delta 上算注意力：

```
标准 Attention:
  score(q_t, k_j) = q_t · k_j          ← 直接用原始表示

KDA（概念性）:
  Δq_t = q_t - q_{t-1}                  ← query 的变化
  Δk_j = k_j - k_{j-1}                  ← key 的变化
  score(q_t, k_j) = f(q_t, k_j, Δq_t, Δk_j)   ← 结合原始值和变化
```

#### 为什么"关注变化"有道理

| 理由 | 描述 |
|------|------|
| **冗余性** | 相邻 token 的表示高度相似（尤其长文本中），直接算 $QK^T$ 有大量冗余计算 |
| **语义转折** | 重要的语义转折往往在"变化"处——token 突然变得不同意味着新信息出现 |
| **效率** | 如果变化 $\Delta k$ 是稀疏的（大部分 token 间变化很小），可以跳过变化小的位置 |

#### KDA 与 Day 4 方案的关系

| 方案 | 核心思路 | 复杂度 | 与 KDA 的关系 |
|------|---------|--------|--------------|
| Full Attention | 全部 token 互相 attend | $O(n^2)$ | KDA 的"前身"——KDA 在此基础上引入 delta |
| DSA | 压缩→选择→精算 | $O(n \cdot k)$ | DSA 稀疏化"选哪些"，KDA 改"怎么算"——可叠加 |
| 线性注意力 | 核函数替换 softmax | $O(n \cdot d^2)$ | 线性注意力改"softmax"，KDA 改"表示"——不同层面 |
| **KDA** | **在 delta（变化量）上算注意力** | **取决于 delta 的稀疏性** | 新层面——改"注意力作用在什么表示上" |

> 💡 **回答 Day 7 自测题：KDA 和 AttnRes 分别属于架构的哪一层创新**？
> - **KDA 属于注意力层创新**——改的是"注意力怎么算"，和 MLA/DSA/线性注意力同一层
> - **AttnRes 属于残差/连接层创新**——改的是"层间怎么传递信息"，是 Transformer 的残差连接层面
> - 两者正交：KDA 管子层内部的注意力计算，AttnRes 管子层之间的信息传递——可以叠加使用（K3 正是这么做的）

> ⚠️ **读论文提醒**：KDA 的具体数学公式（delta 怎么定义、怎么和标准注意力结合、复杂度精确分析）需要从 K3 技术报告原文获取。上面的描述是概念性框架——精读时重点关注：① delta 的具体定义（是简单差分还是可学习变换）；② KDA 和 MLA 是否兼容（K3 是否在 MLA 基础上加 KDA）；③ 1M token 上下文时 KDA 的实际复杂度。

### 学习任务 4：K3 全景 —— 2.8T 参数的效率工程（45 分钟，今日核心）

#### K3 的规模声明

| 指标 | 值 | 对比 |
|------|-----|------|
| **总参数** | **2.8T** | 全球首个开源 3T 级模型 |
| 激活参数 | 约 32-49B（具体见技术报告） | K2 是 32B，V4-Pro 是 49B |
| 上下文窗口 | **1M token** | V4 也是 1M；V3 原生 128K |
| 视觉能力 | 原生多模态（非外挂 vision encoder） | V3/V4 纯文本 |
| 架构创新 | KDA + AttnRes | 前代 K2 无架构层创新 |

#### 回答关键问题：K3 为什么敢做到 2.8T？

Day 1 学过：MoE 的"总参数 vs 激活参数"解耦让模型可以"用小价钱买大脑子"。K3 敢到 2.8T，靠的是六重效率技术叠加：

| 效率技术 | 作用 | 前几日连接 |
|---------|------|-----------|
| **MoE 稀疏激活** | 2.8T 总参但每 token 只激活 ~32-49B | Day 1：V3 的 671B/37B 同理 |
| **DSA 稀疏注意力** | 1M token 上下文的注意力计算可负担 | Day 4：DSA 省 98% 计算 |
| **AttnRes** | 更深网络也能稳定训练，一致 scaling 收益 | 今天任务 2 |
| **KDA** | delta 注意力降低冗余计算 | 今天任务 3 |
| **MuonClip** | 万亿级训练零 loss spike | Day 3：K2 的 Muon + QK-clip |
| **FP8 训练** | 计算量和通信量减半 | Day 3：V3 的 tile-wise scaling |

#### 2.8T 参数的拆解思路

按 Day 1 笔算 V3 671B 的方法，K3 的 2.8T 大致结构（具体数字以技术报告为准）：

| 部分 | 估算占比 | 说明 |
|------|---------|------|
| MoE 专家参数 | ~90% | 更多专家（K2 有 ~数千专家，K3 可能更多） |
| 注意力参数（KDA + MLA） | ~3-5% | 注意力参数通常占小头（Day 1：V3 是 10.7B/671B ≈ 1.6%） |
| Embedding + 输出头 | ~2-3% | 词表 × 隐藏维度 |
| AttnRes 门控参数 | ~1% | 额外的门控矩阵，参数量小 |
| 稠密层 + 共享专家 | ~3-5% | 前几层稠密 + 共享专家 |

> 💡 **核心洞察**：K3 的 2.8T 中约 90% 是 MoE 专家参数——但这些参数在推理时**绝大部分不激活**。每 token 只激活 ~32-49B（约占 1-2%），推理成本和 K2/V4-Pro 相当。"2.8T"听起来吓人，但激活参数的控制让它**不会比 1T 模型贵太多**——这就是 MoE 的威力。

#### K3 相比 K2 的架构演进

| 维度 | K2 | K3 |
|------|-----|-----|
| 总参数 | ~1T | **2.8T**（~3×） |
| 激活参数 | 32B | ~32-49B（基本持平） |
| 注意力 | 标准（MLA 或 GQA） | **KDA**（新型 delta 注意力） |
| 残差连接 | 标准残差 | **AttnRes**（注意力调制） |
| 优化器 | MuonClip | MuonClip（沿用） |
| 上下文 | 未公开（推测 128K-256K） | **1M** |
| 多模态 | 纯文本 | **原生视觉** |
| 定位 | Agentic 智能 | 全能 + 极限规模 |

> ⚠️ **K3 的关键策略**：不是"什么都换新"，而是**在关键架构层（注意力 + 残差）做创新 + 保留验证过的训练技术（MuonClip）+ 规模化 MoE**。这是一种"稳中求进"的策略——AttnRes 和 KDA 是创新点，但 MoE/MuonClip/FP8 是 Day 3 验证过的"保底技术"。

| 训练 | FP8 + DualPipe（沿用 V3） | 同 |
| 定位 | 商业化长上下文 | 通用基座 |

> 💡 **连接 Day 4**：V4 默认 1M 上下文正是靠 Day 4 学的 DSA 实现的——DSA 把 1M token 的注意力计算从 2 EFLOPs/层砍到 ~2%。V4 = V3 架构 + DSA 稀疏注意力 + 更大 MoE 规模。这就是 Day 4 说的"DSA 让 V4 敢默认 1M 上下文"的精确含义。

### 学习任务 6：Nemotron 3 Super 对照 —— Mamba-Transformer 混合路线（25 分钟）

泛读 NVIDIA《Nemotron 3 Super》报告。如果说 K3 是"Transformer 内部创新"（KDA + AttnRes 都在 Transformer 框架内），Nemotron 走的是另一条路——**混合不同架构范式**。

#### Mamba / SSM 回顾

Mamba（2023）基于状态空间模型（SSM），核心机制：

$$h_t = \bar{A} h_{t-1} + \bar{B} x_t, \quad y_t = C h_t$$

- $h_t$：隐藏状态（固定大小，不随序列长度增长——和 Day 4 线性注意力同理）
- $\bar{A}, \bar{B}$：由输入 $x_t$ 动态决定（selective mechanism）
- 复杂度：$O(n \cdot d^2)$——线性于序列长度

| 特性 | Transformer Attention | Mamba SSM |
|------|----------------------|-----------|
| 复杂度 | $O(n^2)$ | $O(n)$ |
| KV cache | 随 $n$ 线性增长 | 固定状态 $h$ |
| 精确检索 | 强 | 弱（信息压进固定状态） |
| 长上下文 | 贵（除非用 DSA/稀疏） | 天然便宜 |

#### Nemotron 的混合架构

Nemotron 3 Super 的策略：**不是全部用 Mamba，也不是全部用 Transformer，而是混着用**：

```
Nemotron 混合架构（示意）:
Layer 0:  [Mamba SSM]          ← 长程信息压缩
Layer 1:  [Mamba SSM]
Layer 2:  [Transformer Attn]   ← 精确检索
Layer 3:  [Mamba SSM]
Layer 4:  [Mamba SSM]
Layer 5:  [Transformer Attn]   ← 周期性插入
...
+ MoE FFN（所有层共用）
```

这和 Day 4 的 Kimi Linear 混合架构（线性层 + 周期性 Full Attention + 滑动窗口）思路相似——用 SSM/Mamba 做长程廉价信息压缩，周期性插入 Transformer 做精确检索。

#### K3 vs Nemotron：两条路线

| 维度 | K3（Transformer 内创新） | Nemotron（混合范式） |
|------|------------------------|---------------------|
| 核心策略 | 在 Transformer 框架内创新（KDA + AttnRes） | 混合 Transformer + Mamba SSM |
| 注意力 | KDA（delta 注意力） | Mamba SSM 层 + 周期性 Transformer |
| 残差 | AttnRes（注意力调制） | 标准残差 |
| FFN | MoE | MoE |
| 长上下文 | DSA 稀疏化（在注意力内做减法） | Mamba 天然 $O(n)$（换架构做减法） |
| 路线哲学 | **演化**（改进现有） | **革命**（引入新范式） |
| 生态兼容 | 高（仍是 Transformer，推理引擎改动小） | 中（需支持 SSM 层的推理引擎） |

> 💡 **演化 vs 革命**：K3 的路线是"在 Transformer 里改零件"——MLA→KDA、标准残差→AttnRes，每个改动都即插即用、向下兼容。Nemotron 的路线是"换引擎"——部分层从 Transformer 换成 Mamba SSM，需要新的推理基础设施。两条路线都在解决长上下文效率问题，但哲学不同：K3 认为"Transformer 还能优化"，Nemotron 认为"Transformer 需要被补充"。

> ⚠️ **没有绝对优劣**：K3 的演化路线生态友好（推理引擎改动小），但受限于 Transformer 框架；Nemotron 的革命路线可能突破 Transformer 的理论上限，但工程迁移成本高。2026 年中两条路线并存，尚未分出胜负——这也是 Day 7 整合时要思考的"架构方向往哪走"。

### 面试题积累（今日 3 道）

**Q16：Attention Residuals 和 ResNet 的残差连接本质区别是什么？为什么能带来一致 scaling 收益？**
> ResNet 残差是恒等映射——$h' = h + F(h)$，输入 $h$ 以固定权重 1 无差别地跳过子层，所有维度获得相同的保留强度。AttnRes 把恒等映射换成注意力调制的门控——$h' = h \odot \alpha(h) + F(h) \odot \beta(h)$，每个维度的保留/变换强度由注意力机制动态计算，内容相关。本质区别是"固定 vs 学习""无差别 vs 维度专属"——标准残差假设所有维度都该同等跳过，AttnRes 打破这个假设让模型自己学最优调配。带来一致 scaling 收益的三个原因：① 深层适配——标准残差在深层累积过大，AttnRes 门控可自适应调低深层残差强度；② 维度专精——不同维度承载不同语义，需要不同的留/变比例；③ 优化更稳——门控提供额外梯度调节路径。AttnRes 是标准残差的超集（$\alpha{=}1, \beta{=}1$ 时退化），所以它能"学到不比标准残差差"的结果。

**Q17：K3 为什么敢做到 2.8T？激活参数多少？靠哪些效率技术兜底？**
> K3 的 2.8T 中约 90% 是 MoE 专家参数，但每 token 只激活约 32-49B（约占 1-2%）——推理成本和 K2（1T/32B）或 V4-Pro（1.6T/49B）相当，不会比 1T 模型贵太多。六重效率技术叠加兜底：① MoE 稀疏激活（总参/激活解耦，Day 1）；② DSA 稀疏注意力（1M 上下文注意力计算省 98%，Day 4）；③ AttnRes（更深网络稳定训练，一致 scaling 收益）；④ KDA（delta 注意力降低冗余计算）；⑤ MuonClip（万亿级训练零 loss spike，Day 3）；⑥ FP8 训练（计算和通信减半，Day 3）。核心策略是"在关键架构层做创新 + 保留验证过的训练技术 + 规模化 MoE"——AttnRes 和 KDA 是创新点，MoE/MuonClip/FP8 是 Day 3 验证过的保底技术。

**Q18：K3 的 KDA 和 AttnRes 分别属于架构的哪一层创新？两者能叠加吗？**
> KDA 属于**注意力层创新**——改的是"注意力怎么算"，用 delta（token 间的变化量）替代原始表示做注意力计算，和 MLA/DSA/线性注意力同一层。AttnRes 属于**残差/连接层创新**——改的是"层间怎么传递信息"，用注意力门控替代标准恒等残差，是 Transformer 的残差连接层面。两者正交：KDA 管子层内部的注意力计算，AttnRes 管子层之间的信息传递——作用在不同层面，可以且应该叠加使用（K3 正是这么做的）。这就是为什么 K3 同时引入两者——一个解决"注意力怎么算更高效"，一个解决"深层网络怎么传信息更稳定"，组合效果大于各自单独贡献。
