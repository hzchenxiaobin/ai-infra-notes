# C++ 面试一周冲刺学习计划

> 适用对象：有一定 C++ 基础，目标为 1~5 年经验岗位的中高频面试题
> 学习主线：基础语法 → 内存管理 → 面向对象 → STL → 现代 C++ → 并发 → 综合冲刺
> 每日节奏建议：上午学理论（2~3h）→ 下午刷题自测（2h）→ 晚上手写代码 + 复述（1~2h）

---

## Day 1（周一）：语言基础 + 关键字

**核心目标**：把最常被"随口一问"的基础题答扎实。

### 学习内容
- 指针 vs 引用（区别、使用场景、能否为 nullptr、sizeof 结果）
- `const` 的各种用法：常量指针 / 指针常量、const 成员函数、const 返回值
- `static`：静态局部变量、静态成员、静态函数、全局 static 的作用域限制
- `inline`、`extern`、`volatile`、`mutable`、`explicit`
- 宏 vs const vs inline vs enum（#define 的坑）
- 类型转换：`static_cast` / `dynamic_cast` / `const_cast` / `reinterpret_cast`

### 高频面试题自测
- [ ] const 指针和指向 const 的指针怎么区分？
- [ ] 为什么析构函数要声明成 virtual？（预热 Day 3）
- [ ] volatile 能保证线程安全吗？（不能，预热 Day 6）

### 动手练习
- 用引用实现 swap
- 写一个禁止拷贝的类

---

## Day 2（周二）：内存管理 ⭐（重中之重，必考）

### 学习内容
- 内存分区：栈、堆、全局/静态区、常量区、代码区
- new/delete vs malloc/free（区别、原理、能否混用）
- 内存泄漏的常见场景与排查（Valgrind、ASan 简单了解）
- 堆栈溢出、野指针、悬空指针、double free
- 内存对齐：为什么要对齐、`sizeof` 结构体怎么算

### 高频面试题自测
- [ ] new 一个对象时发生了什么？（operator new + 构造函数）
- [ ] delete this 合法吗？
- [ ] 数组 new[] 为什么必须配 delete[]？
- [ ] 如何检测内存泄漏？

### 动手练习
- 写一个结构体计算 sizeof（含内存对齐）
- 故意制造一个内存泄漏，再用 ASan 抓出来

---

## Day 3（周三）：面向对象 + 类机制

### 学习内容
- 构造函数 / 析构函数 / 拷贝构造 / 赋值运算符，调用顺序
- 深拷贝 vs 浅拷贝（必考）
- 虚函数机制：虚表、虚表指针、虚函数调用开销
- 纯虚函数、抽象类、接口
- 多态的实现原理、静态绑定 vs 动态绑定
- 继承中的构造/析构顺序、菱形继承与虚继承
- 友元、重载 vs 覆盖（重写） vs 隐藏

### 高频面试题自测
- [ ] 虚函数表存在哪？每个类几个？对象几个虚表指针？
- [ ] 构造函数里能调用虚函数吗？会发生什么？
- [ ] 为什么 C++ 默认析构函数不是虚的？

### 动手练习
- **手写一个完整 String 类**（构造、析构、拷贝构造、赋值运算符）——经典手写题，必须能默写

---

## Day 4（周四）：STL 容器与算法

### 学习内容
- 各容器底层实现：
  - vector（动态数组、扩容机制）
  - list（双向链表）
  - deque（分段连续）
  - map/set（红黑树）
  - unordered_map/set（哈希表）
- vector 扩容为什么是 2 倍 / 1.5 倍、push_back 的复杂度分析
- 迭代器失效问题（vector 扩容、erase 时）
- 哈希冲突解决：链地址法、开放寻址
- 空间配置器（allocator）概念级了解
- 常用算法：sort（内省排序）、find、lower_bound

### 高频面试题自测
- [ ] map 和 unordered_map 区别？什么时候用哪个？
- [ ] vector 如何安全删除元素？
- [ ] 红黑树 vs AVL 树 vs 哈希表，STL 为什么选红黑树？

### 动手练习
- 用 vector 模拟扩容过程，观察 capacity 变化
- LeetCode 刷题 2~3 道：两数之和、LRU 缓存（LRU 是 C++ 岗超高频手写题）

---

## Day 5（周五）：现代 C++（C++11/14/17，区分度所在）

### 学习内容
- **智能指针（必考）**：unique_ptr / shared_ptr / weak_ptr，循环引用问题
- 左值/右值、移动语义、`std::move`、完美转发 `std::forward`
- 拷贝构造 vs 移动构造；Rule of Three / Five
- lambda 表达式：捕获方式、底层原理（仿函数）
- auto、decltype、范围 for、nullptr、constexpr
- 右值引用与引用折叠、万能引用

### 高频面试题自测
- [ ] shared_ptr 是怎么实现计数的？线程安全吗？（计数是原子的，指向的对象不安全）
- [ ] 为什么要有移动语义？`std::move` 到底做了什么？
- [ ] weak_ptr 解决什么问题？如何检测对象是否存活？

### 动手练习
- 给 Day 3 的 String 类加上移动构造和移动赋值
- 写一个简易版 shared_ptr（面试官超爱让写）

---

## Day 6（周六）：多线程与并发

### 学习内容
- 进程 vs 线程；`std::thread` 基本用法
- 互斥锁 mutex、lock_guard、unique_lock、读写锁
- 条件变量 condition_variable（虚假唤醒、配合 while 使用）
- 死锁的四个必要条件与避免方法（加锁顺序、std::lock）
- atomic 原子操作、内存序（memory_order 概念级）
- 单例模式：**双重检查锁 DCLP + atomic / 局部静态变量两种方式都要会写**

### 高频面试题自测
- [ ] 如何实现一个线程安全的单例？
- [ ] 生产者-消费者模型怎么写？
- [ ] volatile 和 atomic 的区别？

### 动手练习
- 手写一个生产者-消费者队列
- 手写线程安全的懒汉单例

## 优先级提示

如果时间不够，可以砍掉 Day 6 的内存序和 Day 7 的 C++20，但以下**四大件一个都不能省**，几乎每场 C++ 面试必问：

1. 内存管理（new/delete、内存分区、内存泄漏）
2. 虚函数机制（虚表、多态原理）
3. 智能指针（shared_ptr/weak_ptr、循环引用）
4. 深拷贝 vs 浅拷贝

**手写题是分水岭**：String 类、shared_ptr、单例这三道出现率极高，建议练到不看资料 10 分钟写完。
