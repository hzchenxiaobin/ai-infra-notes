# 深度学习零基础一周入门计划

> 目标：建立整体认知 + 动手跑通第一个神经网络
> 每天投入：约 3~5 小时（可弹性调整）

---

## 总体路线

```
Day 1-2: 打地基（数学直觉 + 核心概念）
Day 3-4: 动手跑通第一个模型（Python + PyTorch）
Day 5-6: 进阶两大经典网络（CNN + RNN/Transformer）
Day 7: 综合实战 + 复盘
```

**前置建议**：如果 Python 不熟，每天额外花 1 小时补 Python 基础（变量、列表、函数、类即可，不用精通）。

---

## 每日计划

### Day 1｜建立直觉：什么是机器学习与深度学习

- [ ] **上午**：看 3Blue1Brown《神经网络》系列视频前 2 集（B 站有中字），建立"神经网络 = 函数拟合"的直觉
- [ ] **下午**：了解基本概念——监督/无监督学习、训练集/测试集、过拟合
- [ ] **晚上**：搭好环境——安装 Python、Anaconda、PyTorch（或直接用 Google Colab，零配置，推荐新手）

✅ **产出**：能用自己的话解释"神经网络是怎么学习的"

---

### Day 2｜核心概念攻坚

- [ ] **上午**：搞懂梯度下降和反向传播（3Blue1Brown 第 3、4 集），不用推公式，理解"误差往回传、参数慢慢调"即可
- [ ] **下午**：认识关键组件——损失函数、激活函数（ReLU）、学习率
- [ ] **晚上**：在 Colab 里用 NumPy 手写一个最简单的梯度下降（拟合一条直线）

✅ **产出**：手写 20 行代码让一条直线拟合数据点

---

### Day 3｜第一个神经网络：手写数字识别（MNIST）

- [ ] **全天**：跟着教程用 PyTorch 搭建全连接网络识别手写数字
  - 推荐：PyTorch 官方 60 分钟入门教程，或李沐《动手学深度学习》第 3-4 章（免费开源，B 站有配套视频）
- [ ] 重点理解四步：**准备数据 → 定义网络 → 训练循环 → 评估准确率**

✅ **产出**：跑通 MNIST，准确率达到 97%+，并逐行理解代码

---

### Day 4｜调参与训练技巧

- [ ] **上午**：学会看训练曲线，理解 epoch、batch size、过拟合 vs 欠拟合
- [ ] **下午**：动手实验——改学习率、加层数、加 Dropout，观察准确率变化
- [ ] **晚上**：了解 GPU 加速（Colab 免费 GPU 怎么用）

✅ **产出**：一份自己的"调参实验记录"（哪个改动让准确率升/降了）

---

### Day 5｜卷积神经网络 CNN（图像方向）

- [ ] **上午**：理解卷积的直觉——为什么 CNN 适合看图（卷积核 = 特征探测器）
- [ ] **下午**：用 CNN 替换昨天的全连接网络重做 MNIST，或挑战 CIFAR-10（彩色图片分类）

✅ **产出**：CNN 模型跑通，理解卷积层、池化层的作用

---

### Day 6｜序列模型与 Transformer 概览

- [ ] **上午**：了解 RNN/LSTM 的用途（处理序列：文本、语音、时间序列）
- [ ] **下午**：重点放在 **Transformer**——它是当前所有大模型（GPT、Claude）的基础，推荐 Jay Alammar 的《The Illustrated Transformer》（有中文翻译版）

✅ **产出**：能讲清楚"注意力机制"在干什么

---

### Day 7｜综合小项目 + 复盘

- [ ] **选一个小项目完成**（三选一）：
  1. 猫狗图片分类器（Kaggle 上有现成数据集和参考代码）
  2. 文本情感分析（判断影评是好评还是差评）
  3. 用预训练模型做迁移学习（Fine-tune 一个 ResNet）
- [ ] **晚上复盘**：画一张一周知识地图，列出"我懂了什么 / 还模糊什么"

✅ **产出**：一个完整跑通的小项目 + 后续学习清单
