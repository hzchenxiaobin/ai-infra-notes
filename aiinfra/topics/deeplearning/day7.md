### 项目 A：猫狗图片分类器（图像方向）

综合运用：数据加载、CNN、训练循环、调参。

**任务**：给一张图片，判断是猫还是狗。

- **数据集**：Kaggle 搜 "Dogs vs Cats"（2.5 万张图片）；嫌大可以先抽 2000 张做 mini 版
- **参考路线**：
  1. 用 `torchvision.datasets.ImageFolder` 加载图片（把图片按 `cats/`、`dogs/` 分文件夹放好即可，这是最省事的加载方式）
  2. 图片 resize 到统一尺寸（如 128×128），`transforms.Resize((128,128))`
  3. 搭一个 3~4 层的 CNN（参考 Day 5，输入通道 3）
  4. 输出层改成 2 类（或 1 个输出 + `BCEWithLogitsLoss`）
  5. 目标准确率：mini 数据集 70%+ 就算成功
- **加分项**：做数据增强（`transforms.RandomHorizontalFlip()`、`RandomRotation(10)`），观察准确率变化，想想为什么增强能抗过拟合

### 项目 B：文本情感分析（文本方向）

综合运用：序列处理、Embedding、训练循环；体验 Day 6 的知识落地。

**任务**：判断一条电影评论是好评还是差评。

- **数据集**：IMDB 影评数据集（`torchtext` 内置，或 Hugging Face `datasets.load_dataset("imdb")`）
- **两条路线，按兴趣选**：
  - **路线 1（动手派）**：词表 → Embedding → 简单 LSTM 或均值池化 → 分类，全程自己写。能到 85%+ 就很棒
  - **路线 2（实用派）**：用 Hugging Face `pipeline("sentiment-analysis")` 体验预训练模型，再试试 `Trainer` 微调一个 DistilBERT。体验"站在巨人肩膀上"
- **思考**：路线 1 和路线 2 的准确率差距来自什么？（预训练：模型已经在海量文本上"读过书"了）

### 项目 C：迁移学习 Fine-tune ResNet（推荐，性价比最高）

综合运用：CNN、预训练模型、工程思维——**最接近真实工作场景**的项目。

**任务**：用别人训练好的 ResNet-18，微调后完成一个你自己的分类任务（如猫狗分类，或 flowers 数据集）。

**核心思想**：ResNet 在 120 万张 ImageNet 图片上训练过，它的卷积层已经学会了"看"世界的通用本领（边缘、纹理、形状）。我们只需**保留它的特征提取能力，替换最后的分类头**：

```python
from torchvision import models

model = models.resnet18(weights="IMAGENET1K_V1")   # 加载预训练权重

# 冻结前面的卷积层（不更新它们的参数，省显存、训练快）
for param in model.parameters():
    param.requires_grad = False

# 替换分类头：ResNet 原本输出 1000 类，改成你的类别数（如 2 类）
model.fc = nn.Linear(model.fc.in_features, 2)

# 之后照常用老熟人训练循环：只有新分类头的参数会被更新
optimizer = optim.Adam(model.fc.parameters(), lr=0.001)
```

- **震撼点**：通常几个 epoch 就能到 90%+，比自己从零训练的 CNN 高一大截
- **思考**：为什么迁移学习用小数据集就能取得好效果？这对"数据不够"的实际项目意味着什么？
