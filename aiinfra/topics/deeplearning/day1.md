### 看的时候要抓住的核心直觉

**1. 神经网络是什么？**

一个神经网络本质上就是一个**非常复杂的函数**：

```
输入（如 784 个像素值） → [ 神经网络 ] → 输出（如 0~9 是哪个数字）
```

它和 `y = ax + b` 没有本质区别，只是参数从 2 个变成了几百万个。

**2. 每一层在干什么？**

```
输出 = 激活函数( w₁x₁ + w₂x₂ + ... + wₙxₙ + b )
```

- **权重（w）**：每个输入有多重要
- **偏置（b）**：整体的"门槛"高低
- **激活函数**：给函数加入"非线性"，让它能拟合弯曲的边界（否则再多层也等价于一层）

**3. "学习"是什么意思？**

学习 = 不断调整 w 和 b，让网络的输出越来越接近正确答案。第 2 集会讲调整的方向怎么算（梯度下降），今天有个印象即可，Day 2 再深入。

### 概念速览

**监督学习 vs 无监督学习**

| | 监督学习 | 无监督学习 |
| --- | --- | --- |
| 数据 | 有标准答案（标签） | 没有标签 |
| 例子 | 给猫狗照片+答案，学会分类 | 给一堆新闻，自动分成几类主题 |
| 本周重点 | ✅ 全部内容都是监督学习 | 了解即可 |

**训练集 / 测试集**

- **训练集**：给模型"做题"用的数据（带答案）
- **测试集**：模型从没见过的数据，用来"考试"

为什么不能拿训练集考试？因为模型可能只是**背下了答案**，而不是真的学会了。就像考前做过原题，考满分不代表学懂了。

**过拟合（Overfitting）**

模型在训练集上表现很好，但在新数据上一塌糊涂——它记住了训练数据的每一个细节（包括噪声），而没有学到通用规律。

```
欠拟合：学得太少，训练集上都做不好（比如用直线拟合曲线）
刚刚好：抓住了规律，新数据上表现也不错
过拟合：学得"太细"，把噪声也当规律背下来了
```

### 验证环境（两种方案都要跑）

在 Notebook / Python 里运行：

```python
import torch

# 1. 确认 PyTorch 安装成功
print(torch.__version__)

# 2. 确认是否有 GPU 可用（Colab 开了 GPU 应为 True，本地 CPU 版为 False 也正常）
print("GPU 可用:", torch.cuda.is_available())

# 3. 跑一个小运算，感受"张量"（tensor）——深度学习里的基本数据类型
x = torch.tensor([1.0, 2.0, 3.0])
y = torch.tensor([4.0, 5.0, 6.0])
print("x + y =", x + y)          # 逐元素相加
print("x · y =", torch.dot(x, y)) # 点积 = 32.0
```

看到版本号和张量运算结果，环境就搭好了。
