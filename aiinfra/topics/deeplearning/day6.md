### 什么是序列数据

前几天的图片是"一坨同时存在的数据"。但世界上还有大量数据是**有先后顺序**的：

```
文本："我 爱 北京 天安门"       —— 词的顺序决定含义
语音：声波按时间展开            —— 顺序就是一切
股价：今天的价格依赖昨天        —— 时间序列
```

### 为什么全连接/CNN 不够用

核心问题：**它们没有"记忆"**。

读句子"这道菜太咸了，我再也不想来这家店了，真的"——判断情感倾向时，最后一个词"真的"是什么意思，取决于前面读过的所有词。全连接网络把整句话当一次性输入，没有"边读边记住前文"的机制。

### RNN：边读边记

RNN（循环神经网络）的核心思想一句话：**每读一个词，就把"目前为止的理解"压缩进一个隐藏状态，带着它去读下一个词**。

```
读"我"     → 隐藏状态 h₁ = f(输入"我", h₀)
读"爱"     → 隐藏状态 h₂ = f(输入"爱", h₁)   ← 记着"我"
读"北京"   → 隐藏状态 h₃ = f(输入"北京", h₂) ← 记着"我爱"
...
```

隐藏状态 h 就像你读书时脑子里不断更新的"当前理解"。

### RNN 的致命缺陷

**1. 记性差（长距离依赖问题）**

句子长了之后，开头的信息在层层传递中被稀释——读到第 100 个词时，早就忘了第 1 个词说了什么。就像传话游戏，传到最后面目全非。

**2. 没法并行（训练慢）**

必须一个词一个词按顺序算（h₂ 依赖 h₁），无法像 CNN 那样全体一起算。GPU 的并行优势发挥不出来。

### LSTM：给 RNN 加个"记事本"

LSTM（长短期记忆网络）在 RNN 基础上加了一套"门控机制"：模型自己学会**哪些信息该记住、哪些该忘掉**，记性明显改善，统治了 2010 年代的 NLP。

但它依然是逐个词串行处理——**慢**的问题没解决。于是 2017 年，Transformer 登场，把 RNN 整个换掉了。

### 核心思想：注意力机制（Attention）

Transformer 抛弃了"逐词记忆"，换了个思路：**每个词都直接"看"句子里所有其他词，并决定该对谁投入多少关注**。

以句子 "The animal didn't cross the street because **it** was too tired" 为例：

```
理解 "it" 时，注意力权重可能是：
  The:      2%
  animal:  45%   ← 重点关注！"it" 指的是 animal
  didn't:   3%
  cross:    5%
  street:  15%
  tired:   25%   ← "tired" 也帮助理解语境
  ...
```

"it" 不再依赖一个脆弱的、逐词传递的隐藏状态，而是**直接和所有词连线**，按权重把相关信息"加权求和"过来。距离再远也不怕——第 1 个词和第 100 个词之间只隔一次注意力计算。

### Q、K、V：注意力怎么算（理解这层就够了）

每个词生成三个向量：

- **Query（查询）**："我在找什么信息"
- **Key（键）**："我能提供什么信息"（相当于自己的标签）
- **Value（值）**："我实际携带的信息内容"

```
第 1 步：用 "it" 的 Query 去和每个词的 Key 算相似度 → 得到关注权重
第 2 步：按权重对所有词的 Value 加权求和 → 得到 "it" 的新表示
```

直觉类比：查字典。Query 是你要查的问题，Key 是每个词条的标题，Value 是词条的内容。标题和问题越匹配，你越认真读那条内容。

### Transformer 为什么赢

| | RNN/LSTM | Transformer |
| --- | --- | --- |
| 长距离依赖 | 差，信息逐词传递会丢失 | 好，任意两词直接连线 |
| 并行计算 | 不行，必须按顺序 | 全部词同时算，GPU 火力全开 |
| 可扩展性 | 堆不深 | 可以堆几百层、几千亿参数 |

加上一个关键设计——**位置编码**（因为并行计算时词序信息丢了，需要额外把"第几个词"编码进去），Transformer 成了今天 GPT、Claude、BERT 等所有大模型的骨架。

### 你今天只需要建立的整体图景

```
输入文本 → 拆成 token → 词向量 + 位置编码
        → [多头自注意力 + 前馈网络] × N 层堆叠
        → 输出（下一个词的概率 / 分类结果 / ...）
```

**多头注意力（Multi-Head）**：同时用好幾组 Q/K/V，让模型从不同角度关注句子（一组看指代关系、一组看语法、一组看语义……），细节以后再说。

不用写代码训练 Transformer（那是一周的量），用 Hugging Face 直接调用预训练模型，感受大模型的能力：

```python
# Colab 里先装：pip install transformers
from transformers import pipeline

# 情感分析——明天 Day 7 的项目之一可能用到它
classifier = pipeline("sentiment-analysis")

# [{'label': 'POSITIVE', 'score': 0.9998}]

# 填空——直观感受 BERT 的"理解力"

```

## 常见坑提醒

1. **不要陷入矩阵维度推导**——今天的目标是直觉，"注意力分数 = Q·Kᵀ 再 softmax"这个公式眼熟即可，推导留到以后
2. **不要把 RNN 当成过时知识跳过**——理解 RNN 的缺陷，才能理解 Transformer 为什么伟大
3. **Hugging Face 首次调用要下载模型**（几百 MB），耐心等待，或配镜像 `HF_ENDPOINT=https://hf-mirror.com`
4. **"词向量/Embedding"如果陌生**：它就是"把词变成一串数字"——语义相近的词，数字也相近。知道这点就够今天用了
