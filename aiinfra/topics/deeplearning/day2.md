### 要抓住的核心直觉

**1. 损失函数：给"错误"打个分**

训练的第一步是量化"模型现在错得有多离谱"，这个分数叫**损失（loss）**。

以拟合直线 `y = wx + b` 为例，最常用的损失是**均方误差（MSE）**：

```
loss = (1/n) · Σ (预测值 - 真实值)²
```

预测越准，loss 越小。训练的目标就是：**找到让 loss 最小的 w 和 b**。

**2. 梯度下降：蒙眼下山**

把 loss 想象成一座山的高度，参数 w、b 是你站的位置。你想走到谷底（loss 最小），但蒙着眼睛，怎么办？

> 每一步都踩一踩周围，朝**最陡的下坡方向**走一小步，重复很多次，就能走到谷底。

- "最陡的下坡方向" = **梯度（gradient）的反方向**
- "走多大一步" = **学习率（learning rate）**
- 数学表达：`w ← w - 学习率 × ∂loss/∂w`（对 b 同理）

**3. 反向传播：算出"每个参数该为错误负多少责"**

网络有几百万个参数，怎么知道每个参数该往哪调？答案是从输出层开始，**把误差逐层往回传**：

```
输出层的误差 → 倒数第二层的每个参数贡献了多少误差 → 再往前一层 → …
```

这就是链式求导法则的应用。今天不需要会推公式，只需要理解：**反向传播是一套高效计算所有参数梯度的方法，梯度算出来后就交给梯度下降去更新参数**。

一句话总结整个训练过程：

```
前向传播算出预测 → 损失函数量化误差 → 反向传播算出每个参数的梯度 → 梯度下降更新参数 → 循环
```

### 组件一：损失函数（Loss Function）

| 损失函数 | 适用场景 | 直觉 |
| --- | --- | --- |
| MSE（均方误差） | 回归问题（预测连续数值，如房价） | 预测值和真实值的平均距离 |
| 交叉熵（Cross Entropy） | 分类问题（如手写数字识别） | 正确答案的预测概率越高，loss 越小 |

本周的 MNIST 项目用的是交叉熵，今晚的手写练习用 MSE，两个都会见到。

### 组件二：激活函数（Activation Function）

昨天说过，激活函数给网络加入非线性。最常用的 **ReLU** 简单到不可思议：

```
ReLU(x) = max(0, x)    # 负数变 0，正数不变
```

为什么非线性必不可少？因为**线性函数的叠加仍然是线性函数**——没有激活函数，100 层网络和 1 层网络的表达能力完全一样，根本拟合不了复杂的弯曲边界。加上 ReLU 这样的"折弯"操作后，层数越多，能拟合的函数就越复杂。

其他常见激活函数知道名字即可：Sigmoid、Tanh、Softmax（输出层做分类时用）。

### 组件三：学习率（Learning Rate）

学习率控制梯度下降每步迈多大：

```
学习率太大 → 步子太大，在谷底两边来回跳，甚至越跳越高（发散）
学习率太小 → 步子太小，走得对但慢，训练半天没进展
学习率合适 → 稳定下降，loss 曲线平滑走低
```

常用起始值：`0.01`、`0.001`。Day 4 会亲手做对比实验，今天先记住它是**最重要的超参数**。

> **超参数**：人手动设定的参数（如学习率、层数、batch size），区别于模型自己学出来的参数（w、b）。

## 晚上｜动手：NumPy 手写梯度下降

这是本周第一个真正动手的练习，**一定要自己敲，不要复制粘贴**。

### 任务

用纯 NumPy（不用 PyTorch）实现梯度下降，拟合一条直线 `y = wx + b`。

### 目标代码（约 20 行，先自己尝试，卡住再对照）

```python
import numpy as np
import matplotlib.pyplot as plt

# 1. 造数据：真实规律是 y = 3x + 2，加一点噪声
np.random.seed(42)
x = np.linspace(0, 10, 50)
y = 3 * x + 2 + np.random.randn(50) * 2

# 2. 随机初始化参数
w, b = 0.0, 0.0
lr = 0.01          # 学习率
epochs = 1000      # 迭代次数

# 3. 梯度下降主循环
for epoch in range(epochs):
    y_pred = w * x + b                          # 前向：算预测值
    loss = np.mean((y_pred - y) ** 2)           # 算损失（MSE）
    dw = np.mean(2 * (y_pred - y) * x)          # loss 对 w 的梯度
    db = np.mean(2 * (y_pred - y))              # loss 对 b 的梯度
    w -= lr * dw                                # 梯度下降：更新参数
    b -= lr * db
    if epoch % 100 == 0:
        print(f"epoch {epoch:4d} | loss {loss:.4f} | w {w:.3f} | b {b:.3f}")

# 4. 画图看效果
plt.scatter(x, y, label="data")
plt.plot(x, w * x + b, color="red", label=f"fit: y={w:.2f}x+{b:.2f}")
plt.legend()
plt.show()
```

### 代码与概念的对应关系（逐行理解的重点）

| 代码 | 对应概念 |
| --- | --- |
| `y_pred = w * x + b` | 前向传播 |
| `loss = np.mean((y_pred - y) ** 2)` | 损失函数（MSE） |
| `dw`、`db` | 反向传播（这里网络只有 1 层，梯度可以直接写出来） |
| `w -= lr * dw` | 梯度下降更新 |
| `lr` | 学习率 |

> 梯度怎么来的？对 MSE 求导：`∂loss/∂w = mean(2·(y_pred - y)·x)`，`∂loss/∂b = mean(2·(y_pred - y))`。看不懂推导没关系，知道"它是 loss 对参数的变化率"即可。
