## 1. 题目概述

- **题目名称**：Q1. 给定数位和的最大整数
- **链接**：[4000. 给定数位和的最大整数](https://leetcode.cn/problems/largest-integer-with-given-digit-sum/)
- **来源**：LeetCode 第 512 场周赛 Q1
- **难度**：简单
- **标签**：贪心、数学

**题意简述**：

给定非负整数 $n$ 和 $s$，返回**最多 $n$ 位**、**各位数字之和等于 $s$** 的**最大**整数（字符串形式亦可，不包含前导零）。若不存在则返回 `-1`。

**约束条件**：

- $1 \le n \le 5$
- $0 \le s \le 100$

## 2. 示例

**示例 1**

```text
输入：n = 2, s = 9
输出：90
解释：最多 2 位且数位和为 9 的最大整数是 90（9+0=9）。
```

**示例 2**

```text
输入：n = 2, s = 19
输出：-1
解释：2 位数字最大和为 9+9=18 < 19，无解。
```

**示例 3**

```text
输入：n = 5, s = 0
输出：0
解释：数位和为 0 的唯一非负整数是 0。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有 $0 \sim 10^n-1$ 的整数，检查数位和。$n \le 5$ 时枚举量仅 $10^5$，可行但浪费——本题有 $O(n)$ 的贪心解。

### 3.2 核心观察：贪心填位

![贪心填位：每位放尽可能大的数字](images/digit_sum_greedy.svg)

要使整数最大，**高位尽可能大**。从最高位开始，每位放一个尽可能大的数字 $d \in [0, 9]$，但要保证：

1. $d \le s$（剩余数位和不能超）
2. 剩余 $r = n - i - 1$ 位能容纳剩余和 $s - d$，即 $s - d \le 9r$，亦即 $d \ge s - 9r$

因此每位放 $d = \min(9, s)$，但下界 $d \ge \max(0, s - 9r)$ 兜底（保证后续能凑齐）。

### 3.3 算法流程

1. **特判**：$s = 0$ → 返回 `"0"`（唯一非负整数）；$s > 9n$ → 返回 `"-1"`。
2. 从高位到低位逐位填：第 $i$ 位（$i=0..n-1$），剩余位数 $r = n-i-1$：
   - $d_{\min} = \max(0, s - 9r)$（保证剩余能凑齐）
   - $d = \min(9, s)$，再 $d = \max(d, d_{\min})$
   - 追加 $d$，$s \mathrel{-}= d$
3. 拼接字符串返回（自动无前导零，因为首位取尽可能大的值）。

### 3.4 示例演算

`n=3, s=18`：

| 位 | 剩余位 r | $d_{\min}=\max(0, s-9r)$ | $d=\min(9,s)$ | 实取 | 余 s |
|----|---------|--------------------------|---------------|------|------|
| 0 | 2 | $\max(0, 18-18)=0$ | 9 | 9 | 9 |
| 1 | 1 | $\max(0, 9-9)=0$ | 9 | 9 | 0 |
| 2 | 0 | $\max(0, 0-0)=0$ | 0 | 0 | 0 |

结果 `990` ✓

## 4. 算法细节

1. **不可行判断优先**：$s > 9n$ 时每位都填 9 也不够，返回 `-1`。$s = 0$ 时唯一解是 `0`（不能是 `00...0`）。
2. **下界兜底**：若剩余和 $s$ 较大而剩余位数少，首位不能只填 $\min(9,s)$——例如 $n=2, s=17$，首位若填 9 则余 8，第二位填 8 可行（结果 98）；但若 $n=2, s=18$，首位填 9 余 9，第二位填 9（结果 99）。下界 $d \ge s - 9r$ 保证"剩余和恰好能被剩余位容纳"。
3. **返回类型**：题目返回字符串（`string`），因 $n \le 5$ 时整数也行，但字符串更通用、无前导零问题。

---

## 5. 正确性证明

**引理**：贪心策略每位取 $d = \min(9, s)$（受 $d \ge s - 9r$ 约束）得到全局最大整数。

**证明**：设贪心解为 $A = a_1 a_2 \dots a_n$，任取其他合法解 $B = b_1 b_2 \dots b_n$。考察首个 $a_k \ne b_k$ 的位置 $k$。贪心取 $a_k = \min(9, s_k)$（$s_k$ 为第 $k$ 位时的剩余和），而 $b_k \le a_k$（因 $b_k \le 9$ 且 $b_k \le s_k$）。若 $b_k < a_k$，则 $A$ 在第 $k$ 位更大，$A > B$。下界 $a_k \ge s_k - 9r$ 保证后续可凑齐，故 $A$ 合法且最大。$\square$

**定理**：算法返回最大整数或 `-1`。

**证明**：$s > 9n$ 显然无解。否则贪心由引理得最大整数。$s=0$ 时唯一解为 `0`。$\square$

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。逐位填，每位 $O(1)$。
- **空间复杂度**：$O(n)$。存结果字符串。

> 💡 $n \le 5$ 极小，任何正确方法都能过；贪心 $O(n)$ 是最优。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string largestInteger(int n, int s) {
        if (s == 0) return "0";
        if (s > 9 * n) return "-1";
        string res;
        for (int i = 0; i < n; ++i) {
            int r = n - i - 1;
            int dmin = max(0, s - 9 * r);   // 保证剩余位能容纳
            int d = min(9, s);
            d = max(d, dmin);
            res += char('0' + d);
            s -= d;
        }
        return res;
    }
};
```

### Python

```python
class Solution:
    def largestInteger(self, n: int, s: int) -> str:
        if s == 0:
            return "0"
        if s > 9 * n:
            return "-1"
        res = []
        for i in range(n):
            r = n - i - 1
            dmin = max(0, s - 9 * r)
            d = min(9, s)
            d = max(d, dmin)
            res.append(str(d))
            s -= d
        return "".join(res)
```

## 8. 边界情况与易错点

1. **$s = 0$**：返回 `"0"` 而非 `""` 或 `"00...0"`。唯一数位和为 0 的非负整数是 0。
2. **$s > 9n$**：返回 `-1`。例如 $n=2, s=19$。
3. **$n = 1$**：直接返回 $s$（若 $s \le 9$），否则 `-1`。
4. **下界兜底勿忘**：仅用 $\min(9,s)$ 在 $s$ 大、剩余位少时会失败。例如 $n=1, s=5$ 正确返回 `5`；但若误用首位填 0 会导致错误。
5. **返回字符串**：避免前导零和整数溢出（本题 $n \le 5$ 不溢出，但字符串更稳）。
